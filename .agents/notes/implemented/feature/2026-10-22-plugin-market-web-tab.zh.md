# Agent Note: 插件市场作为 Web“插件”标签页

Status: implemented

[English](2026-10-22-plugin-market-web-tab.md) | 中文

## 问题

市场能力接缝交付了 `market` Remote 命名空间和面向模型的工具，但浏览器无法访问它：想装插件的人仍然要知道 npm 包名，并让 agent 代装。Web 设置面已经有一个由各功能自持标签页组成的“插件”分区，缺少的只是一块浏览器插件，以及一个挂载新命名空间的 Client 组合——`api-remotes` 没有做这件事，因为该组合是显式列出它挂载的每一项 Remote 贡献的。

## 决定

`@deepseek-ai/dsh-client-ui-market` 贡献一项 id 为 `market`、order 为 20 的 `settings.plugins.tab` 贡献，通过 `ctx.slots.inject()` 注册。分区拥有方保留导航行与标签栏；标签页拥有自己的展示级标题行、搜索框、结果卡片与文案。`ui-settings-plugin-inventory` 是模板：本地化注册、包裹两个 Remote 调用的 inject face，以及把加载、空结果、无匹配结果和失败状态都留在已挂载标签页内部的组件。

`@deepseek-ai/dsh-api-remotes` 在它原本挂载的四项贡献旁挂载 `@deepseek-ai/dsh-market/remote`，并以 type-only 形式重新导出其声明合并，因此消费端经由该组合外观写 `ctx.remote.market.search` 与 `ctx.remote.market.install`。载荷类型来自 `@deepseek-ai/dsh-market/types`——一次 type-only 导入，因此浏览器 bundle 不携带任何 Host 运行时代码。

首次浏览查询（`dsh`）在用户选择**测试连接**后执行，遵循[连接测试决策](../bug-fix/2026-10-21-market-client-activation.md)。此后输入经 300 毫秒防抖合并为一次请求；空输入回到浏览查询。提供方拒绝空查询，因此空字符串无法请求更宽的列表。

每张卡片是一处紧凑折叠区：包名、版本、截断的说明和安装控件始终可见；展开后显示完整说明、以带标签事实呈现的版本与发布时间，安装后还会显示配置目录与重启提示。同一时间只展开一张卡片，结果列表在标签页内部滚动，因此很长的注册表答复不会撑高设置页面。安装状态按卡片划分（`pending` → `installed` | `failed`），并且只属于组件本身：安装这件事不跨标签页共享，安装按钮仅在该卡片请求进行中或已成功后被禁用。安装成功会展开对应的卡片，因为配置目录与重启要求正是这次点击要的答案。

安装请求只携带包名。能力支持锁定精确版本，但标签页没有版本输入框，加一个没人要求的控件才叫多余。

## 考虑过的替代方案

**把标签页做进 `ui-settings-plugins`。** 分区拥有方将因此承担另一个功能的 Remote 依赖、搜索生命周期与安装状态。标签扩展点存在的意义正是让插件视图作为独立包发布。

**由 `ui-market` 自己挂载 `market` Remote。** `ctx.remote.$mount` 属于组合的职责：由一个地方决定本应用暴露哪些 Host 命名空间；让功能包自行挂载，会让暴露集合取决于组合恰好加载了哪些功能插件。

**在本地按浏览文本过滤结果。** 注册表已返回按相关度排序的候选，提供方也已剔除非插件；再做一层本地过滤，只是在同一批字符串上第二个更弱的匹配定义。

**每张卡片一个带版本输入框的折叠安装面板。** 锁定版本所需的版本号搜索结果已经知道，另外提供一个可填任意版本的输入框，只会带来只有跑完包管理器才能被拒绝的输入错误。

**安装后自动刷新清单。** 在重启之前，已安装的插件对运行中的 Loader 不可见，结果列表不会变化；刷新只会为同一批条目再发一次注册表查询。

## 后果

用户可以直接在浏览器里搜索市场并安装插件，结果会告诉它装到了哪里、需要重启。该标签页继承了接缝的两条限制：安装只有重启后才有用，市场 wire 不广播注册表变化，因此清单是一份会被下一次查询替换的快照。

Client 组合因此多命名一个 Host 包。新增命名空间仍然是 `api-remotes` 里一次显式的值导入与挂载，那里的顺序规则——按挂载的逆序回退——无需改动即覆盖新贡献。

`packages/bundle/web-app` 增加了 `dsh.client` 行以及该行所需的依赖；浏览器半侧拨号的是 base 层的 `market` 网关行。

## 测试

`packages/client/ui-market/tests/components.client.spec.tsx` 用桩 inject face 驱动组件：浏览查询、防抖输入、空结果与无匹配文案、重试、单卡安装成功与失败（含重启提示缺席的情形）、折叠状态，以及卸载后才返回的结果。`browser-plugin.client.spec.tsx` 固定 inject 列表、注册选项、本地化标签、延迟声明与声明方重载，以及两个 Remote 包装的失败映射。`invariant.client.spec.ts` 让伴随插件与 node 半侧保持惰性。
