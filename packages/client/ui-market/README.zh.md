# @deepseek-ai/dsh-client-ui-market

[English](README.md) | 中文

Web 设置 → 插件中的**插件市场**标签页可搜索已发布的插件并安装到当前配置。浏览器插件注册一个 id 为 `market` 的本地化 `settings.plugins.tab` 贡献；“插件”分区拥有导航入口与标签栏。应用启动和打开标签页均不发送市场请求。选择**测试连接**后才执行首次浏览查询并显示结果。搜索与安装在调用时读取可选的 `remote.market` 服务，因此 API 不可用时只在设置中显示错误，不会阻塞应用启动。[`api-remotes`](../../api/remotes/README.md) 负责挂载生成的 Market 命名空间。

标签页以一个展示级标题、一个搜索框和每个结果一张紧凑折叠卡片打开。卡片始终显示包名、当前版本、截断后的说明和安装控件；展开后会显示完整说明、版本、注册表发布时间，以及安装后的落位配置目录与重启提示。同一时间只展开一张卡片，结果列表在标签页内部滚动，因此很长的注册表答复不会撑高设置页面。输入会经防抖合并为一次请求；清空输入会回到浏览查询。加载、空结果、无匹配结果与通用失败状态只属于本标签页；读取失败可以重试，并且任何状态都不暴露传输细节。安装始终指向最新已发布版本，因为标签页不提供版本输入框。注册使用 `ctx.slots.inject()`，因此能跟随标签 slot 的延迟声明、重新声明、本地化变化与 teardown，而无需 import 分区拥有方。

## 模型体验

无，因为本包只渲染浏览器设置界面，不注册任何模型接口；模型只能通过被安装插件自身的 Host 行接触它。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **安装要重启后生效** —— 运行中的进程无法挂载 Loader 在启动时没有解析过的包，因此安装结果会报告 `restartRequired`，标签页显示配置目录与重启提示，而不会声称插件已经可用。
- **清单是一份快照，不是订阅** —— 市场 wire 不广播注册表变化，标签页展示的是最近一次查询的结果；重新查询或重试才会再次读取。
- **浏览依赖注册表启发式** —— 索引按文本匹配，只有 manifest 带 `dsh` 字段的包才算插件，因此一次浏览查询列出的候选可能多于可安装的插件，而发布元数据没有提到 DSH 的插件只能靠点名它的查询找到。
- **安装总是取最新已发布版本** —— 请求载荷支持锁定版本，但标签页不提供版本输入框，因此始终只发送包名。
